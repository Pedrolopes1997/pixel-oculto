Privacy Policy

Last updated: October 22, 2026

Pixel Oculto Uploader ("the app") is an internal tool used only by the owner of the YouTube channels @OPixelOculto and @HiddenPixelHQ to upload videos to those channels.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

  • Upload permission (youtube.upload): used only to upload videos to the signed-in account's own channel.
  • Read-only channel info (youtube.readonly): used only to show the channel name before uploading, to avoid sending a video to the wrong channel.

The app does not read, collect or store comments, subscribers, viewers or any other user's data.

How data is stored and shared

  • The authorization token is stored only on the owner's own computer and is never sent anywhere else.
  • No data is sold, shared with third parties, or used for advertising.
  • A local log keeps only the ID of each uploaded video, to avoid duplicate uploads.

Revoking access

Access can be revoked at any time at Google Account → Security → Third-party access. Deleting the local token file also removes the app's access from the computer.
